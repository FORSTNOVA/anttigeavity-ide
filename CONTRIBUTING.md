# Contributing to Antigravity Usage & Quota Dashboard

Thank you for your interest in contributing to **Antigravity Usage & Quota Dashboard**! We welcome all contributions, whether they are bug reports, feature requests, documentation improvements, or pull requests.

## 🛠️ Development Setup

1. **Clone the repository**:
   ```bash
   git clone <repository-url>
   cd antigravity-usage-dashboard
   ```

2. **Run tests**:
   ```bash
   npm test
   ```

3. **Install locally into Antigravity IDE**:
   ```bash
   node install.js
   ```
   Then reload your Antigravity IDE window (`Ctrl+Shift+P` -> `Developer: Reload Window`).

## 📋 Pull Request Process

1. Fork the repo and create your branch from `main`:
   ```bash
   git checkout -b feat/your-feature-name
   ```
2. Make your changes and adhere to existing code styles.
3. Run tests locally:
   ```bash
   npm test
   ```
4. Commit your changes using semantic commit messages:
   - `feat:` new feature
   - `fix:` bug fix
   - `docs:` documentation updates
   - `refactor:` code refactoring
   - `test:` adding or updating tests
5. Push to your fork and submit a Pull Request describing your changes clearly.

## 🐛 Reporting Issues

If you encounter bugs or have suggestions, please open an Issue with:
- A clear, descriptive title.
- Steps to reproduce the issue.
- Your OS and Antigravity IDE version.
- Any relevant logs or screenshots.
